3. Sơ Đồ Tuần Tự Ghép Trận Online 2v2 Tag-Team

Luồng điều phối hàng chờ MatchmakingQueue: phân cặp đối xứng Team Alpha (Ghế 0 & 2) vs Team Omega (Ghế 1 & 3) và khởi tạo bàn đấu.

sequenceDiagram
    autonumber
    actor PlayerA as Đấu thủ A (Ghế 0)
    actor PlayerB as Đấu thủ B (Ghế 1)
    participant ClientA as Client UI (A)
    participant ClientB as Client UI (B)
    participant Gateway as Socket Gateway
    participant Queue as MatchmakingQueue
    participant Engine as OnlineGame Engine

    PlayerA->>ClientA: Bấm "Ghép Người Online 2v2"
    ClientA->>Gateway: emit("matchmaking:join", { mode: "2V2_TEAM" })
    Gateway->>Queue: addToQueue("2V2_TEAM", playerA)
    Queue-->>ClientA: emit("matchmaking:searching", { queueSize: 1 })

    PlayerB->>ClientB: Bấm "Ghép Người Online 2v2"
    ClientB->>Gateway: emit("matchmaking:join", { mode: "2V2_TEAM" })
    Gateway->>Queue: addToQueue("2V2_TEAM", playerB)

    alt Quá 60s chờ -> Tự động chèn Bot
        Queue->>Queue: Auto-fill Bot Neon (Alpha) & Bot Titan (Omega)
    end

    Queue->>Queue: createMatchedRoom("2V2_TEAM")
    Note over Queue: Ghế 0 & 2: Team ALPHA (Cyan)
Ghế 1 & 3: Team OMEGA (Rose)

    Queue->>Engine: new OnlineGame(room)
    Engine->>Engine: Khởi tạo bộ bài 108 lá, chia 7 lá/đấu thủ

    Queue-->>ClientA: emit("matchmaking:found", { roomCode, seatIndex: 0, team: "ALPHA" })
    Queue-->>ClientB: emit("matchmaking:found", { roomCode, seatIndex: 1, team: "OMEGA" })

    Engine-->>ClientA: emit("game:state_sync", { fullClientState, teammateCardSummary })
    Engine-->>ClientB: emit("game:state_sync", { fullClientState, teammateCardSummary })

    ClientA->>ClientA: Bật màn hình 2v2, hiển thị Soi bài Đồng Đội
    ClientB->>ClientB: Bật màn hình 2v2, hiển thị Soi bài Đồng Đội

4. Sơ Đồ Tuần Tự Vòng Lặp Lượt Đánh & Xử Lý Lá Bài

Cơ chế xác thực quyền lượt đi, luật bài UNO chống gian lận, áp dụng lá bài phạt (+2, +4, Skip, Reverse) và chuyển lượt 15s.

sequenceDiagram
    autonumber
    actor Player as Đấu thủ (Đến lượt)
    participant Client as Client GameBoard
    participant Gateway as Socket Gateway
    participant Engine as OnlineGame Engine
    participant Timer as Turn Timer (15s)

    Timer-->>Client: emit("game:timer_tick", { turnTimeRemaining: 15..0 })
    Player->>Client: Bấm chọn lá bài (+2 Đỏ)
    Client->>Gateway: emit("game:play_card", { cardId })

    Gateway->>Engine: handlePlayCard(userId, cardId)
    Engine->>Engine: Xác thực quyền lượt đi & lá bài trên tay
    Engine->>Engine: Kiểm tra luật UNO: trùng màu hoặc trùng ký hiệu

    alt Lá bài HỢP LỆ
        Engine->>Engine: Rút lá bài khỏi tay -> Đặt lên Discard Pile
        opt Nếu là lá bài phạt (+2, +4, Skip, Reverse)
            Engine->>Engine: Cộng dồn drawStack += 2 hoặc Đảo chiều vòng
            Engine-->>Client: emit("game:action_event", { type: "draw_two" })
        end
        Engine->>Timer: Đặt lại đồng hồ 15s
        Engine->>Engine: advanceTurn(nextSeatIndex)
        Engine-->>Gateway: Broadcast trạng thái bàn cờ
        Gateway-->>Client: emit("game:card_played", { playerSeat, card })
        Gateway-->>Client: emit("game:state_sync", { activeDiscard, currentTurnIndex })
    else Lá bài KHÔNG HỢP LỆ
        Engine-->>Client: emit("game:action_error", { message: "Nước đi không hợp lệ!" })
    end

5. Sơ Đồ Tuần Tự Báo UNO & Kết Thúc Trận Đấu

Đếm ngược 5 giây bắt buộc hô UNO khi còn 1 lá bài, phạt bốc 2 lá khi bị bắt quả tang, và quy trình tính thưởng ELO khi ván kết thúc.

sequenceDiagram
    autonumber
    actor PlayerA as Đấu thủ A (Còn 1 lá)
    actor PlayerB as Đấu thủ B (Đối thủ)
    participant ClientA as Client UI (A)
    participant ClientB as Client UI (B)
    participant Engine as OnlineGame Engine
    participant DB as MongoDB Atlas

    PlayerA->>ClientA: Đánh lá áp chót (Còn đúng 1 lá)
    ClientA->>Engine: emit("game:play_card", card)
    Engine-->>ClientA: emit("game:uno_warning", { timeLimit: 5 })
    Engine-->>ClientB: emit("game:uno_warning", { timeLimit: 5 })

    alt Kịch bản 1: Bấm Báo UNO kịp thời (< 5s)
        PlayerA->>ClientA: Bấm "BÁO UNO"
        ClientA->>Engine: emit("game:call_uno")
        Engine-->>ClientA: emit("game:uno_called", { success: true })
    else Kịch bản 2: Quên bấm (> 5s) -> Bị bắt quả tang
        PlayerB->>ClientB: Bấm "BẮT UNO"
        ClientB->>Engine: emit("game:catch_uno", { targetSeat: 0 })
        Engine->>Engine: Phạt PlayerA bốc thêm 2 lá bài
        Engine-->>ClientA: emit("game:uno_penalized", { penaltyCards: 2 })
    end

    Note over PlayerA,Engine: Đấu thủ A đánh lá bài cuối cùng (0 lá)
    PlayerA->>ClientA: Đánh lá cuối
    ClientA->>Engine: emit("game:play_card", finalCard)
    Engine->>Engine: finishGame(winnerPlayerA)

    Engine->>DB: Match.create(replayData)
    Engine->>DB: User.updateMany(Cộng/Trừ ELO, Vàng, EXP)

    Engine-->>ClientA: emit("game:finished", { winner, rankings, rewards })
    Engine-->>ClientB: emit("game:finished", { winner, rankings, rewards })
    ClientA->>ClientA: Bật Modal Chiến Thắng Vô Địch
    ClientB->>ClientB: Bật Modal Kết Quả Trận Đấu

7. Sơ Đồ Máy Trạng Thái Bàn Đấu (State Machine Diagram)

Chu trình vòng đời của bàn cờ: Sảnh chờ → Ghép trận → Chia bài → Vòng lặp lượt đánh → Báo UNO → Kết thúc và ghi nhận Replay.

stateDiagram-v2
    [*] --> LOBBY : Ở Sảnh Chính

    LOBBY --> MATCHMAKING : Bấm Ghép Trận (1v1, 4P, 2v2)
    MATCHMAKING --> IN_ROOM : Đủ Đấu Thủ / Chèn Bot

    LOBBY --> IN_ROOM : Tạo / Vào Phòng Bạn Bè

    IN_ROOM --> DEALING : Bắt Đầu Trận
    DEALING --> TURN_WAITING : Chia Xong 7 Lá Bài

    state TURN_ACTIVE {
        [*] --> WAITING_INPUT : Đếm Ngược 15 Giây
        WAITING_INPUT --> CARD_PLAYED : Đánh Lá Hợp Lệ
        WAITING_INPUT --> DRAW_CARD : Bốc Bài (Tối Đa 2 Lá)
        WAITING_INPUT --> AFK_WARNING : Hết 15 Giây

        AFK_WARNING --> BOT_TAKEOVER : Bot Đánh Hộ
        BOT_TAKEOVER --> WAITING_INPUT : Lấy Lại Quyền

        CARD_PLAYED --> RESOLVE_ACTION : Áp Dụng +2, +4, Skip, Reverse
        RESOLVE_ACTION --> CHECK_UNO : Kiểm Tra Số Lá Trên Tay

        CHECK_UNO --> UNO_ALERT : Còn 1 Lá (Đếm Ngược 5s)
        UNO_ALERT --> UNO_SAFE : Báo UNO Kịp Thời
        UNO_ALERT --> UNO_CAUGHT : Bị Bắt Quả Tang (+2 Lá)

        UNO_SAFE --> NEXT_TURN
        UNO_CAUGHT --> NEXT_TURN
        DRAW_CARD --> NEXT_TURN
    }

    TURN_WAITING --> TURN_ACTIVE
    NEXT_TURN --> TURN_ACTIVE : Chuyển Lượt Đi

    TURN_ACTIVE --> GAME_OVER : Có Người Hết Bài (0 Lá) / Hết Giờ 5 Phút

    state GAME_OVER {
        [*] --> COMPUTE_REWARDS : Tính ELO, Vàng, EXP
        COMPUTE_REWARDS --> PERSIST_REPLAY : Lưu MongoDB Match
        PERSIST_REPLAY --> VICTORY_MODAL : Bật Modal Vinh Danh
    }

    GAME_OVER --> LOBBY : Quay Về Sảnh
